# Declaracion de uso de IA

## Uso de IA durante implementacion MVC Repository

- ChatGPT fue utilizado para analisis arquitectonico y revision de la implementacion propuesta.
- OpenCode fue utilizado como asistente de ejecucion controlada dentro del worktree asignado.
- La revision humana se realizo mediante revision de codigo, ejecucion de pruebas y revision Git.

La IA no realizo una generacion automatica completa sin supervision. Las decisiones, cambios y verificaciones fueron revisados en el contexto del modulo ASII-13.
